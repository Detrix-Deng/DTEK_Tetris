initiate a clock that interrupts 300 times / sec. The idea is to have an interrupt handler that updates the screen for every 10 timeoutcount, which should make the game run with 30 fps. labinit will be in main.
void labinit()    // Clock times out (TO) every 10/3 ms
{
  *(time_addr + 2) = (100000 - 1) & 0x0000FFFF;    // Set lower half
  *(time_addr + 3) = (100000 - 1) >> 16;    // Set upper half
  *(time_addr + 1) = 7;
  enable_interrupt();
}
